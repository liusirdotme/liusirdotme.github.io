你永远赚不到超出你认知范围之外的钱，除非靠着运气；但是运气赚到的钱，最后往往又会靠着实力亏掉，这是一种必然的趋势。

AWS Cloud Practitioner / 阿里云ACA云计算 / 腾讯云从业者 对比&备考路线

版本说明：AWS CLF-C02、阿里云云计算ACA、腾讯云从业者认证（Tencent Cloud Practitioner）

一、基础信息对比表

项目 AWS Cloud Practitioner（CLF-C02） 阿里云云计算工程师 ACA 腾讯云从业者认证
定位 入门从业者，通用云认知，不绑定岗位 阿里云入门基础认证，产品识别+基础选型 对标AWS Practitioner，腾讯云全景入门
考试时长 90分钟 90分钟 90分钟
题量 65题（含15道不计分） 50题（单选+多选+判断） 60题：单选40、多选20
合格线 700/1000 70/100 70/100
考试形式 线上/线下考点 线上机考 线上理论考试
费用 约100USD 600元（订单含2次机会，1年内） 官网可查，价格更低
语言 中英可选 中文 中文
进阶路线 SAA→DVA→SysOps等 ACP→ACE TCCA→TCCP

二、考试大纲&分值权重对比

AWS Cloud Practitioner（CLF-C02）

模块 权重 核心考点
云概念 Cloud Concepts 24% 云计算价值、云优势、架构设计原则、迁移策略、CAP、弹性/可扩展性
安全与合规 Security and Compliance 30% 共享责任模型、IAM、加密、合规体系、安全最佳实践、日志审计
云技术与服务 Technology & Services 34% EC2、S3、RDS、VPC、Lambda、SQS/SNS、DynamoDB、基础AI/大数据服务，区分产品适用场景
账单定价与支持 Billing & Support 12% 计费模式、预留实例、Savings Plans、预算、Cost Explorer、Support计划

特点：非常看重共享责任模型、安全合规、云理念；不考复杂配置，重在“识别服务、选场景”

阿里云 云计算ACA

模块 权重 核心考点
云计算基础 10% IaaS/PaaS/SaaS、虚拟化、云优势、上云价值
弹性计算（ECS） 25% ECS实例、镜像、快照、弹性伸缩ESS、停机/计费模式
云网络（VPC/SLB） 20% VPC、安全组、NAT、SLB负载均衡、路由、网络隔离
云存储（OSS/块存储） 15% OSS、块存储、文件存储、冷热分层、访问权限
云数据库RDS 10% RDS主从、备份、只读实例、DTS、数据库选型
云容器 10% ACK基础概念、容器基础
云安全 & 监控 10% RAM、DDoS、WAF、云监控、安全职责划分

特点：偏国内阿里云产品细节，ECS、VPC、SLB占比很高；国内业务、等保相关内容

腾讯云从业者认证

模块 权重 核心考点
腾讯云概览 3% 腾讯云生态、产品线全景
云计算基础 13% 云计算基础概念、交付模式、上云价值
基础设施（计算/网络/存储） 27% CVM、CLB、VPC、COS、CBS、CFS、CDN
云数据库 10% MySQL、PostgreSQL、TDSQL、DBbrain、迁移
中间件 5% Redis、消息队列等基础认知
安全产品 12% CAM、WAF、DDoS、密钥、审计
大数据/AI/企业应用 15% 混元、大数据、音视频、企业应用
计费与成本 5% 计费方式、包年包月/按量、成本优化

特点：结构最贴近AWS Practitioner，产品广度大，音视频、混元AI是特色考点

三、三者核心差异一句话总结

  1. AWS CLF-C02：重云理念、安全合规、共享责任模型，产品是案例，适合外企、海外业务、云原生通用认知；
  2. 腾讯云从业者：结构对齐AWS，广度最大，音视频、AI是特色，国内互联网、微信生态业务优先；
  3. 阿里云ACA：国内普及度最高，ECS/VPC/SLB权重极高，传统政企、阿里云生态项目优先。

四、备考路线（3套方案，按需选择）

前提：零基础建议先统一理解云计算通用概念（IaaS/PaaS/SaaS、弹性、高可用、共享安全模型），这部分是互通的

路线A：只考AWS Cloud Practitioner（CLF-C02，推荐想建立通用云思维）

  1. 第1周：云概念 + 共享责任模型（重中之重，30%分值）
  2. 第2周：核心服务识别（EC2/S3/RDS/VPC/Lambda/SQS/SNS），区分适用场景
  3. 第3周：计费、成本工具、Support计划、合规（SOC、GDPR等）
  4. 第4周：刷题 + 错题复盘，重点练“场景选型题”

    资料：AWS官方Exam Guide、官方免费课程、A Cloud Guru/Stephane Maarek课程、题库

路线B：国内路线，阿里云ACA（适合国内政企、阿里云项目）

  1. 第1周：云计算基础 + ECS（分值最高25%），吃透实例、快照、伸缩
  2. 第2周：VPC、SLB、安全组、NAT（网络模块20%，高频坑点）
  3. 第3周：OSS、RDS、RAM、云安全、云监控
  4. 第4周：刷题，区分阿里云各存储、数据库产品差异

    资料：阿里云培训中心官方课程、产品文档、ACA题库

路线C：国内路线，腾讯云从业者（对标AWS Practitioner，想一套思维迁移）

  1. 第1周：云计算基础 + CVM、VPC、CLB、COS（基础设施）
  2. 第2周：数据库、安全CAM/WAF/DDoS
  3. 第3周：CDN、音视频、AI/混元、中间件
  4. 第4周：刷题，重点区分腾讯云全家桶产品定位

    资料：腾讯云培训认证免费课、产品文档

五、同时备考（先通用，再差异化）最优顺序

如果你想三个都学，推荐顺序：

  1. 先学 AWS Cloud Practitioner：建立标准云思维、安全模型、架构原则（底层思想通用）
  2. 再学腾讯云从业者：框架对齐AWS，上手最快，对比理解国内云差异
  3. 最后阿里云ACA：产品细节多，国内项目场景多，单独记忆ECS/VPC/SLB体系

避坑提醒：

  • AWS的IAM ≈ 阿里云RAM ≈ 腾讯云CAM，是同一个东西，名字不同；
  • 共享责任模型三家都考，AWS考得最深；
  • 国内云证书考题大量是产品功能对比、国内合规（等保），AWS是海外合规。

六、选择建议

  • 外企、海外业务、想通用云原生基础：AWS CLF-C02
  • 国内政企、阿里云项目、国内求职运维/售前：阿里云ACA
  • 腾讯生态、音视频、互联网业务、想对标AWS体系：腾讯云从业者
