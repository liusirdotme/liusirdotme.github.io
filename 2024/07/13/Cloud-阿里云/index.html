Alibaba Cloud Certified Associate

ACA 是阿里云认证体系里的入门级（助理工程师），考的是”产品矩阵识别 + 概念区分 + 基础选型”，不考运维细节和 API 参数。题干基本是场景题：给业务需求，问用哪个产品、为什么。

一、先搞清楚考的是哪一个 ACA

阿里云的 ACA 有两条线，容易混：

版本 状态 说明
国内版：阿里云云计算工程师 ACA（Alibaba Cloud Certified Associate - Cloud Computing） 在考 中文，按培训中心的课程与大纲走
国际版：ACA Cloud Computing 2025 年 3 月 31 日已退役 被 Cloud Engineer (Associate) 取代，海外考这个新证

国内版考试基本信息（以官网/大纲为准，认证政策会调整）：

项目 内容
认证费用 600 元（含 2 次考试机会，订单 1 年有效，首次未过需等 24 小时）
题型 全部选择题：单选 + 多选（多选错选/漏选一般不得分）
时长/及格 常见口径为 60 分钟 / 满分 100 / 80 分及格
考试形式 线上，需实名（有效身份证件）
前置 无，建议先过一遍官方课程 + 实验

老资料里常见的”50 题 / 90 分钟 / 60 分及格”是国际版口径，别拿它准备国内版。考前一定去官网下当前版《考试大纲》——新版（V1）已经比老版多出”可观测、AI 创新、成本治理、卓越架构”几块内容。

二、什么是云计算（10%）

2.1 定义与五大特征

云计算 = 通过网络按需获取可弹性伸缩、可计量的计算资源（算力、存储、网络、软件服务），本质是把”买硬件”变成”买服务”。

必记特征（对应选择题里的”下列哪项属于云计算特征”）：

  1. 按需自助服务：控制台/API 自助开通，不用等采购。
  2. 广泛的网络访问：任何地点、多终端接入。
  3. 资源池化：多租户共享资源池，靠隔离保证安全。
  4. 快速弹性：分钟级扩缩容。
  5. 可计量服务：按使用量计费，成本可核算。

2.2 三种服务模型（必考对应关系）

模型 用户管到哪 阿里云代表产品
IaaS 管 OS 及以上（系统、中间件、应用、数据） ECS、ESSD 云盘、VPC、SLB
PaaS 只管应用与数据 RDS、ACK、函数计算 FC、云效
SaaS 只管用 企业邮箱、宜搭、钉钉、无影（更偏 DaaS）

2.3 部署模型 & 上云价值

部署模型 说明 场景
公有云 多租户共享，按量购买 互联网业务、初创团队
私有云 / 专有云 独享资源，部署在客户机房（Apsara Stack 飞天专有云） 政企、金融、强合规
混合云 核心本地 + 弹性上云，通过专线/VPN/云企业网打通 渐进上云、潮汐业务
社区云 同行业/同区域共用 行业云、园区云

上云价值：CapEx → OpEx、分钟级交付、弹性应对峰值、免运维物理层、多可用区天然容灾、可继承平台合规资质。

三、云上的计算服务（25%，最大块）

3.1 ECS 云服务器（核心中的核心）

必背概念：

概念 要点
地域 Region 物理数据中心所在城市，选地域看”用户距离 + 合规 + 成本”
可用区 Zone 同地域内电力/网络独立的机房，跨可用区部署 = 高可用
实例规格族 决定 CPU/内存/磁盘配比，见下表
镜像 公共镜像、自定义镜像、共享镜像、镜像市场、社区镜像
云盘 系统盘 + 数据盘，性能由 ESSD 的 PL 级别决定
快照 手动/自动快照策略，用于回滚与备份，占用存储容量
安全组 实例级防火墙，规则支持允许 + 拒绝，默认拒绝入方向
弹性网卡 ENI 一机多网卡多 IP，用于高可用与流量分离
实例自定义数据 开机执行脚本，批量初始化

规格族速记（题干给”内存密集型数据库”就选 r 族）：

规格族 代号 特点 用途
通用型 g CPU/内存均衡 Web、中小应用
计算型 c 高主频/高核 批处理、游戏服、HPC
内存型 r 大内存 数据库、缓存、大数据
本地 SSD 型 i 本地 NVMe 高 IOPS 数据库
大数据型 d 大容量本地盘 Hadoop、日志
GPU 型 gn GPU 加速 AI 训练推理、渲染
突发性能型 t 基准+突发积分 轻负载、开发测试
共享型 s 共享资源、超分 个人站、低预算

四种计费/购买方式（最常考）：

方式 付费 价格 适用
包年包月 预付费，买月/年 长期最省 生产环境、长期稳定
按量付费 后付费，按小时 灵活、单价高 临时测试、波动业务
抢占式实例 后付费，价格随供需浮动 最便宜，可能被释放 可中断任务：CI、渲染、离线计算
节省计划 / 预留实例券 承诺消费换折扣 有折扣 用量稳定的中长期

考点判据：长期稳定 → 包年包月；临时波动 → 按量；可中断且想最省 → 抢占式；用量稳定但规格可能变 → 节省计划。

3.2 弹性伸缩 ESS（Auto Scaling）

  • 四要素：伸缩组 + 伸缩配置（用哪套模板）+ 伸缩规则（目标实例数/按指标）+ 伸缩活动（执行记录）。
  • 触发：定时、云监控报警（CPU/内存）、手动执行。
  • 冷却时间：防止反复抖动。
  • 必须配合 SLB 后端服务器组才能把新机器接进流量。
  • 前提：应用无状态（会话别存本机，用 Redis）。

3.3 容器与 Serverless

产品 定位 关键点
ACK 容器服务 Kubernetes 版 托管 K8s 集群/节点池、托管免运维、支持 GPU
ASK / ECI 弹性容器实例 Serverless 容器 无需管节点，按规格计费
ACR 容器镜像服务 镜像仓库 镜像托管、多地域同步、安全扫描
函数计算 FC Serverless 函数 事件驱动、按调用与资源计费、免运维
批量计算 批处理调度 大规模离线作业

判断关键词：不用管服务器、按需付费到零、事件驱动、短任务 → 函数计算 FC；要标准 K8s 编排 → ACK；只要跑个容器镜像 → ECI。

3.4 其他算力

  • GPU 云服务器：AI 训练/推理、图形渲染、视频编码。
  • 弹性裸金属服务器（神龙）：无虚拟化损耗、强隔离，适合数据库、高性能计算。
  • 无影云电脑：桌面即服务（DaaS），终端瘦客户端接入。

四、全球基础设施（5%）

层级 说明 作用
地域 Region 全球多个地域（华北、华东、华南、香港、新加坡、美西等） 数据驻留、合规、就近接入
可用区 AZ 地域内独立机房 跨 AZ 部署实现高可用
边缘节点 CDN 全球节点 静态内容就近分发
全球加速 GA 阿里云全球网络接入点 跨境/跨地域低延迟加速，TCP/UDP 四层加速
云企业网 CEN 多地域多 VPC 一张内网 全球组网、跨地域互通

选地域三要素：用户在哪里、数据合规要求、成本差异（不同地域价格不同）。

五、云网络的隔离与连通（20%）

5.1 VPC 私网

概念 要点
VPC 逻辑隔离的虚拟网络，自定义 CIDR（如 192.168.0.0/16）
交换机 vSwitch VPC 内的虚拟交换机，子网挂在上面
子网 按可用区划分；同 VPC 内子网网段不能重叠
路由表 控制子网流量走向
NAT 网关 私有子网统一出公网，节省 EIP
EIP 弹性公网 IP 可绑定/解绑、可跨实例复用
共享带宽 多 EIP 共用一条带宽，降成本

CIDR 考点：跨 VPC 互通要求网段不重叠；VPC 网段要给未来留余量；子网划分与可用区绑定。

5.2 安全组 vs 其他边界（高频对比）

对比项 安全组 网络 ACL（腾讯云语境）/ 云防火墙
作用层级 实例级（ECS/SLB 绑定） 子网级 / VPC 边界
规则动作 允许 + 拒绝 允许 + 拒绝
状态 同一连接的响应流量默认放行 需双向配置
用途 精细控制某台机器端口 整段子网/跨 VPC 流量管控

和 AWS 的关键差异：阿里云安全组支持”拒绝”规则（AWS 安全组只能 Allow）。这是最容易用旧经验答错的一题。

5.3 负载均衡三兄弟（必考）

产品 层级 特点 场景
CLB 传统型负载均衡 四层/七层 支持 TCP/UDP/HTTP/HTTPS，成熟稳定 通用 Web 服务
ALB 应用型负载均衡 七层 基于规则转发、支持 gRPC/QUIC、更灵活 微服务、容器入口、HTTPS 卸载
NLB 网络型负载均衡 四层 超高性能、支持 TCP/UDP/全端口、大并发连接 游戏、长连接、IoT

必记机制：

  • 监听 → 虚拟服务器组 → 后端服务器（ECS/ENI）；
  • 健康检查：自动摘除异常后端；
  • 会话保持：同一客户端固定落到同一后端（七层可基于 Cookie）；
  • 权重：按机器性能分配流量；
  • 转发策略（ALB）：按域名/路径路由到不同后端组；
  • 证书：HTTPS 卸载在 SLB 上，后端走 HTTP。

5.4 互联与混合云

方案 特点 场景
高速通道 / 专线 物理专线，稳定低延迟 核心业务上云、数据同步
VPN 网关 IPSec 加密隧道，开通快 中小流量、临时互联
云企业网 CEN 多 VPC、多地域、跨账号一张网 企业多地域组网
全球加速 GA 四层加速，就近接入 跨境访问、游戏出海

专线本身不加密，要加密就在专线上叠 VPN 或走 TLS。

六、云上的存储服务（15%）

6.1 三兄弟分工（必考选型）

类型 产品 协议/访问 能挂几台 场景
块存储 ESSD 云盘 / 云盘 挂载为系统盘/数据盘 单台 数据库、系统盘、高 IOPS
文件存储 NAS 文件存储 / CPFS NFS / SMB 多台共享 共享目录、媒体、HPC
对象存储 OSS HTTP API/SDK 无限 图片视频、备份、静态网站、数据湖

6.2 ESSD 云盘

  • 性能分级 PL0–PL3（PL 越高 IOPS 越高，价格越贵）；ESSD AutoPL 可按负载自动升性能。
  • 支持在线扩容（扩完还要在系统内扩分区/文件系统，考题爱问”为什么容量没变”）。
  • 快照：手动/自动策略、可回滚、可做镜像；快照占用存储空间。
  • 云盘与实例同可用区才能挂载，跨区迁移靠”快照 → 新盘”。

6.3 NAS / CPFS

  • NAS：SMB（Windows）+ NFS（Linux），多客户端共享，适合文件共享、媒体素材、备份。
  • CPFS：并行文件系统，高吞吐高 IOPS，适合 HPC、AI 训练数据集。

6.4 OSS 对象存储（考得最细）

概念/能力 要点
Bucket / Object 存储空间（地域级）+ 对象（Key-Value），无真实目录
存储类型 标准、低频访问、归档、冷归档（越冷越便宜、取回越慢，归档需解冻）
数据冗余 本地冗余 LRS（同机房多副本）/ 同城冗余 ZRS（跨可用区，机房级故障不丢）
版本控制 保留历史版本，防误覆盖/误删
生命周期 按规则自动转低频/归档/删除
跨区域复制 异地容灾
静态网站托管 直接托管静态页
图片处理 通过 URL 参数裁剪、缩放、加水印、格式转换
权限 Bucket ACL + RAM 策略 + STS 临时签名 URL（前端直传必须用临时凭证）
传输加速 跨地域上传下载加速

冗余方式这道题特别爱考：要求”机房级故障也不丢数据” → 同城冗余 ZRS；只要单机房内多副本、想省钱 → 本地冗余 LRS。

6.5 选型口诀

七、云上的数据库服务（10%）

7.1 产品全景

类别 产品 说明
关系型托管 RDS（MySQL / SQL Server / PostgreSQL / MariaDB） 开箱即用、自动备份、主备高可用
云原生关系型 PolarDB（MySQL/PG/Oracle 兼容） 计算存储分离、共享存储、一写多读、秒级扩缩容
分布式 PolarDB-X 水平分片、分布式事务
缓存 云数据库 Redis（社区版/企业版，含集群版） 高并发、热点缓存、会话
文档 云数据库 MongoDB 灵活 schema
多模 Lindorm 宽表、时序、搜索、文件多模合一
分析型 AnalyticDB（ADB MySQL 版 / PG 版） 海量 OLAP、报表
备份/迁移 DBS 数据库备份、DTS 数据传输 备份、迁移、实时同步

7.2 必考概念

  • RDS 高可用形态：基础版（单节点，适合测试）、高可用版（主备自动切换）、集群版/三节点企业版（强同步、金融级）。
  • 读写分离：加只读实例分担读流量；或用数据库代理（Proxy）自动做读写分离与连接池——注意只读实例是”扩展读”，不是”高可用”。
  • 备份与恢复：自动备份 + 日志备份，支持按备份集或时间点恢复（PITR），解决误删数据。
  • 迁移：DTS 支持结构迁移、全量 + 增量同步、双向同步。
  • PolarDB 的核心卖点：计算与存储分离、共享存储多读、按需升降配、兼容 MySQL 生态——题干出现”高并发读、弹性扩缩容、兼容 MySQL”优先它。

7.3 托管 vs 自建

维度 RDS/PolarDB 自建在 ECS 上
运维 自动备份、监控、切换 全自己管
高可用 主备自动切换 手工主从 + 切换
弹性 在线升配、加只读 停机迁移
权限 无 OS 权限，受限 完全控制（装插件、改参数）
适用 生产环境、绝大多数业务 特殊版本、强定制、学习

八、云上安全、身份与合规（10%）

8.1 阿里云安全体系（按层记）

数据 密钥、加密、审计 KMS 密钥管理、数据库审计、加密服务
身份与权限 账号、授权、临时凭证 RAM 访问控制

8.2 RAM 访问控制（必考）

概念 要点
主账号 只做管理与授权，日常不用；应开启 MFA
RAM 用户（子账号） 具体操作者，按需授权
权限策略 Policy 定义”能对哪些资源做什么动作”，可自定义
角色 Role 一组策略的集合，用于批量授权与跨账号
STS 临时凭证 有效期短，用于前端直传 OSS、跨服务调用，不要把 AccessKey 写进客户端
SSO 与企业 IdP 打通，统一登录

原则：最小权限 + 权限分离 + 密钥不落代码 + 定期轮换 AccessKey。

8.3 几个必记判断

  • DDoS 高防：抗大流量攻击、隐藏源站；普通 ECS 自带的基础防护能力有限。
  • WAF：防护 OWASP Top 10、CC 攻击、Bot 管理，可接入 CDN/SLB。
  • 云安全中心：主机侧的木马查杀、漏洞检测、基线检查、入侵告警。
  • KMS：托管主密钥，做信封加密；与 OSS/云盘/RDS 集成实现静态加密。
  • 等保：云上可继承平台的物理/网络层合规，但应用与数据层的等保责任仍在自己。

九、云上可观测（5%，新版新增）

产品 定位 关键点
云监控 CloudMonitor 基础设施与应用监控 主机监控（需装 agent）、云服务监控、报警规则、站点监控、应用分组、事件中心
SLS 日志服务 日志采集-存储-查询-告警 Logtail 采集、全文检索、SQL 分析、告警与可视化
ARMS 应用实时监控 APM 应用调用链、慢请求、异常、前端体验

三者分工（易混）：看 CPU/内存/磁盘/网络指标 → 云监控；要查日志内容、做日志分析告警 → SLS；要定位”哪个接口慢、哪次调用出错” → ARMS。

监控三件套的通用逻辑：采集 → 存储 → 告警（阈值/智能异常检测）→ 可视化。

十一、成本与费用（新版新增）

11.1 计费模型

维度 收费方式 考点
计算 包年包月 / 按量 / 抢占式 / 节省计划 长期选包年，临时选按量
存储 按容量 + 按请求/流量（OSS） 冷数据转低频/归档省钱
网络 公网出流量计费，入流量通常免费；带宽按固定带宽或按使用流量 出方向才是钱
数据库 规格（CPU/内存/存储）包年包月，备份空间另计 只读实例按规格加钱

11.2 省钱工具与手段

  • 资源包：OSS 下行流量包、CDN 流量包、短信包——按量业务买资源包比按量付便宜。
  • 节省计划 / 预留实例券：承诺消费换折扣，适合用量稳定。
  • 成本管家 / 费用中心：账单分析、成本分摊、按标签/项目核算。
  • 代金券与活动：新购、续费折扣。
  • 架构层面省钱：冷数据下沉 OSS 归档、用 CDN 减回源、用弹性伸缩避免长期闲置、用抢占式跑离线任务。

易错点：带宽和流量是两笔钱；存储容量和请求次数是两笔钱；备份空间独立计费。

十二、迁移上云

场景 工具
整台服务器迁移（物理机/VM/他云） SMC 服务器迁移中心
数据库迁移与同步 DTS（结构 + 全量 + 增量，支持异构）
对象存储搬迁 OSS 迁移工具 / ossimport
大数据搬迁 DataWorks 数据集成
混合云组网 高速通道 / VPN 网关 / 云企业网 CEN

迁移顺序一般是：评估 → 试点（非核心业务）→ 数据同步 → 切换 → 回滚预案。考点常问”如何保证迁移期间业务不中断”：靠增量同步 + 短暂停写切换 + 回滚方案。

十三、云上卓越架构

阿里云卓越架构（Well-Architected）是把”好架构”拆成几个可评估的维度，用来做自检与改进建议。核心维度：

维度 关键问题 典型手段
稳定可靠 单点故障在哪？故障能否自愈？ 多可用区、SLB 健康检查、RDS 主备、备份与回滚
安全合规 谁能访问什么？数据是否加密？ 安全组最小开放、RAM 最小权限、KMS、等保
性能高效 瓶颈在计算、存储还是网络？ 规格选型、缓存 Redis、CDN、读写分离
成本优化 哪些资源在闲置？ 弹性伸缩、冷热分层、资源包、节省计划
业务敏捷 / 可运维 变更是否可回滚？是否可观测？ 云效流水线、灰度、云监控 + SLS

答题套路：题干给”高可用”→ 多可用区 + 主备 + 健康检查；给”降本”→ 弹性伸缩 + 冷热分层 + 包年包月；给”可运维”→ 监控告警 + 日志 + 流水线。

十六、备考建议

两周节奏：

周 重点 目标
第 1 周 云计算基础 + ECS + 弹性伸缩 + 容器（约 35%） 能说清规格族、三种计费、ESS 四要素
第 2 周 网络 + 存储 + 数据库（约 45%），再补安全/可观测/AI/成本 能画出三层架构并做选型判断

方法：

  • 官方课程 13 个课时过一遍，边看边在控制台开通免费试用产品（ECS、OSS、RDS 都有试用额度），做过实验的选择题基本不会错。
  • 官网下载当前版《考试大纲》，逐条核对本文是否覆盖；新版比老版多了可观测、AI、成本三块，别漏。
  • 及格线 80 分（比 AWS 的 70% 更严），所以不能只抓大块，边角概念也要过一遍。

答题技巧：

  • 多选不确定就少选（错选漏选都不给分）。
  • 看到”长期稳定”→ 包年包月；”临时/波动”→ 按量；”可中断”→ 抢占式。
  • “最省钱”与”最省运维”常互斥，先看清题干问哪个。
  • 不确定时选托管产品、选多可用区，命中率最高。
