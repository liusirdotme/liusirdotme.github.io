你永远赚不到超出你认知范围之外的钱，除非靠着运气；但是运气赚到的钱，最后往往又会靠着实力亏掉，这是一种必然的趋势。

Tencent Cloud Practitioner

腾讯云从业者认证（TCP，Tencent Cloud Practitioner）是入门级认证，考的是”产品矩阵 + 选型判断”，不是运维细节。题干几乎都是场景题：给一个业务需求，问该用哪个产品、为什么。

二、腾讯与腾讯云概述（3%）

2.1 腾讯云是什么

  • 腾讯 1998 年成立于深圳，核心产品 QQ、微信、腾讯游戏；腾讯云是其对外输出的云计算品牌，2010 年起对外开放服务。
  • 定位：不只卖 IaaS，而是”基础设施 + 平台产品 + 行业解决方案“三层输出，覆盖游戏、音视频、社交、金融、政务、教育、电商等行业。
  • 底层优势：腾讯内部海量业务（微信、QQ、游戏）多年沉淀的分布式架构与音视频技术，直接产品化。

2.2 现代网站的工作原理（常作为背景题）

链条上每一环都对应一个腾讯云产品，考题会问”这一层用什么”。

2.3 本地自建 vs 云上

维度 本地机房 云上
成本形态 资本支出 CapEx，一次性买硬件 运营支出 OpEx，按量付费
交付周期 采购+上架，周级到月级 分钟级开通
容量规划 按峰值买，平时闲置 弹性伸缩，按需扩容
运维 自建机房、电力、网络、硬件保修 云厂商负责物理层，你只管配置
容灾 需自建双机房，成本高 多可用区/多地域开箱可用
合规 自己承担等保测评 可继承云平台合规资质

2.4 四种部署模型 + 三种服务模型

部署模型 说明 典型场景
公有云 资源多租户共享，按需购买 互联网业务、创业团队
私有云 专属资源，部署在企业机房或专属云 金融、政务、强合规
混合云 核心在本地、弹性部分在云，通过专线/VPN 打通 渐进上云、潮汐业务
社区云 特定群体（同行业/同区域）共同使用 行业联盟、园区云
服务模型 你负责 腾讯云对应
IaaS OS 及以上全部 CVM、CBS、VPC
PaaS 只负责应用与数据 TencentDB、TKE、SCF、CKafka
SaaS 只使用 企业邮箱、腾讯会议、CODING（SaaS 版）

2.5 云计算的六大优势

  1. 按需自助：控制台/API 自助开通，不用提工单等审批。
  2. 广泛网络接入：任何地点、任何终端可用。
  3. 资源池化：多租户共享资源池，利用率高、单价低。
  4. 快速弹性：分钟级扩容/缩容，应对突发流量。
  5. 可计量服务：按使用量计费，成本可核算、可优化。
  6. 成本与敏捷优势：免去机房与硬件投入，试错成本极低。

三、云计算服务（14%）

3.1 产品全景（先记住”谁是谁”）

产品 定位 一句话
CVM 云服务器 主力 IaaS 虚拟机 弹性可扩展的计算实例
Lighthouse 轻量应用服务器 简化版 VPS 固定套餐、含流量包、开箱建站
裸金属服务器 BM 无虚拟化开销的物理机 高性能、强隔离、适合数据库/高性能计算
专用宿主机 CDH 独享整台物理机 自己划分虚拟机，资源独享、可控超分
GPU 云服务器 加速计算 AI 训练/推理、渲染、视频编码
AS 弹性伸缩 自动增减 CVM 按告警/定时策略扩缩容
TKE 容器服务 托管 Kubernetes 集群/节点池、TKE Serverless
SCF 云函数 Serverless 事件驱动、免运维、按调用计费
批量计算 批处理作业调度 大规模离线计算
主机迁移 CMS / 云数据迁移 CDM 迁移工具 服务器与数据搬迁上云

3.2 CVM 关键考点

规格族命名（题干给”内存密集型数据库”就该选 M 族）：

族 特点 典型用途
S 标准型 CPU/内存均衡 Web 服务、中小型应用
C 计算型 高主频/高核数比 批处理、游戏服务端、高性能计算
M 内存型 大内存 数据库、缓存、大数据分析
I 高 IO 型 本地 NVMe SSD 高 IOPS 数据库、NoSQL
D 大数据型 大容量本地盘 Hadoop、日志处理
GN/GPU 型 GPU 加速 深度学习、图形渲染

三种计费模式（必考对比）：

模式 付费方式 价格 适用
包年包月 预付费，一次性买 1 个月–3 年 最便宜（长期） 长期稳定业务、生产环境
按量计费 后付费，按小时/秒结算 单价高，随时释放 临时测试、流量波动
竞价实例 后付费，价格随供需浮动 最低（可低至按量的一折以下） 可中断任务：渲染、CI、离线计算

竞价实例的考点就一句：便宜但可能被系统回收，所以只能跑”挂了能重跑”的任务；数据库、核心业务绝对不能用。

其他必记点：

  • 镜像四类：公共镜像（官方 OS）、自定义镜像（自己制作）、共享镜像（跨账号共享）、服务市场镜像（带应用的预装镜像）。
  • 快照：基于 CBS，增量存储、可用于回滚与制作镜像；跨地域复制做灾备。
  • 弹性网卡 ENI：一机多网卡、多 IP，用于高可用与流量分离。
  • 置放群组：把实例分散到不同物理机（低关联）或集中（高网络性能），做高可用或高性能。
  • User Data / 初始化脚本：开机自动执行，用于批量配置。

3.3 弹性伸缩 AS

  • 组成：伸缩组 + 启动配置 + 伸缩策略 + 关联 CLB。
  • 触发方式：定时策略（每天 9 点扩容）、告警触发（CPU>70% 扩）、手动。
  • 关键概念：最小/最大实例数、冷却时间（避免反复抖动）、移出策略（先删最老/最新实例）。
  • 前提：应用必须无状态，会话与文件不能存在本机（否则扩出来的机器接不住流量）——这是常考的判断点。

3.4 容器与 Serverless

产品 特点 适用
TKE 托管 K8s，自管节点池，可控性高 已有容器化体系、微服务
TKE Serverless 无需管节点，按 Pod 资源计费 不想维护集群
SCF 云函数 事件触发、自动扩缩、按调用与资源用量计费 定时任务、文件处理、Webhook、轻量 API
容器镜像服务 TCR 镜像仓库 存镜像、跨环境分发

Serverless 的判断关键词：no server to manage、按需付费到零、事件驱动、短时任务。

四、网络服务（13%）

4.1 VPC 基础（最高频）

  • VPC 私有网络：逻辑隔离的虚拟网络，自定义 CIDR（如 10.0.0.0/16）。
  • 子网 Subnet：VPC 内按可用区划分，同一 VPC 内子网网段不能重叠；子网跨可用区部署即天然高可用。
  • 路由表：控制子网出流量走向（默认走 NAT 网关或公网网关）。
  • 公网访问三件套：公网 IP / EIP 弹性公网 IP（可解绑复用）、NAT 网关（私有子网统一出网）、公网网关。

CIDR 规划考点：VPC 网段要给未来留余量；子网划分按可用区；跨 VPC 互通要求网段不重叠（否则只能靠 CCN 转换或重新规划）。

4.2 安全组 vs 网络 ACL（最经典的对比题）

对比项 安全组 网络 ACL
作用层级 实例级（绑定 CVM/CLB 等） 子网级
状态 有状态（去程放行则回程自动放行） 无状态（出入方向都要单独配）
规则动作 支持允许 + 拒绝 支持允许 + 拒绝
匹配方式 规则匹配后生效 按优先级顺序匹配
典型用途 精细控制某台机器开哪些端口 整段子网的粗粒度隔离

和 AWS 的差别记一下：AWS 安全组只支持 Allow，腾讯云安全组允许配置拒绝规则，这是容易被”经验”带错的地方。

4.3 负载均衡 CLB 家族

产品 层级 特点 场景
CLB 传统型 四层/七层 公网/内网，支持 TCP/UDP/HTTP/HTTPS 通用 Web 服务
ALB 应用型 七层 基于转发规则、支持更复杂的路由与弹性能力 微服务、容器入口
GWLB 网关型 三层 把流量透明送给安全设备集群 串接防火墙/入侵检测

必记概念：监听器（前端端口协议）、后端服务器组（CVM/容器/ENI）、健康检查（自动摘除故障节点）、会话保持（同一用户落到同一后端）、跨可用区容灾。

4.4 混合云与互联

方案 特点 适用
专线 DC（Direct Connect） 物理专线，稳定低延迟、带宽独享 核心业务上云、数据同步
VPN 网关（IPSec） 走公网加密隧道，开通快、便宜 临时/中小流量互联
CCN 云联网 多 VPC、多地域、多账号一张网互通 多地域组网、企业多账号
对等连接 Peering 两个 VPC 点对点互通 少量 VPC 互联，不传递
私有连接 PrivateLink 跨 VPC 访问服务，不用打通全网 SaaS 服务方与客户 VPC 对接

专线 + VPN 的关系：专线稳定但本身不加密，要求加密就在专线上叠加 VPN 隧道。

4.5 典型三层 Web 参考架构（画得出来就能答一半题）

每一层的设计理由：CDN 降回源带宽、CLB 做流量分发与故障摘除、Web 层无状态才能弹性、中间件解耦削峰、数据层主备+缓存保证可用与性能。

五、存储服务（13%）

5.1 三类存储的分工（必考选型）

类型 产品 访问方式 可挂几台 场景
块存储 CBS 云硬盘 挂载为系统盘/数据盘 单台（共享盘需集群软件） 数据库、系统盘、高 IOPS 应用
文件存储 CFS NFS / SMB 协议 多台同时挂载 共享目录、媒体处理、大数据、容器持久化
对象存储 COS HTTP API / SDK 无限客户端 图片视频、备份、静态网站、数据湖

5.2 CBS 云硬盘

类型 特点 适用
高性能云硬盘 均衡，性价比高 一般业务、Web 服务器
SSD 云硬盘 高 IOPS、低延迟 数据库、高并发
增强型 SSD 更高性能上限、可调 核心数据库、大型应用

必记能力：

  • 在线扩容：不停机扩容量，但扩容后还要在系统内扩展分区/文件系统（考题常问”扩了容量为什么磁盘没变大”）。
  • 快照：增量、可回滚、可跨地域复制。
  • 多副本：数据多副本存储，保障单点故障不丢数据。
  • 与实例同可用区才能挂载；跨区迁移靠”快照 → 新盘”。

5.3 CFS 文件存储

  • 协议：NFS（Linux）+ SMB/CIFS（Windows），多客户端并发挂载同一目录。
  • 类型：标准型、性能型、吞吐型（按场景选 IOPS 与吞吐）。
  • 典型场景：多台 Web 服务器共享上传目录、视频转码共享素材、容器共享持久卷、大数据中间结果。

5.4 COS 对象存储（考得最细）

  • 基本单位：存储桶 Bucket（地域级）+ 对象 Object（Key-Value），无目录层级（用 / 模拟）。
  • 存储类（按访问频率从热到冷）：
存储类 特点 典型用途
标准存储 高频访问、低延迟 网站图片、音视频源、热数据
低频存储 存储便宜、取回有费用 备份、每月几次访问
归档存储 需解冻（恢复）后读取，分钟级 长期归档、合规留存
深度归档 最便宜、解冻最慢（小时级） 冷备、极少访问的历史数据
  • 关键能力：生命周期规则（自动转低频/归档/删除）、版本控制（防误删覆盖）、跨地域复制、静态网站托管、防盗链、CDN 加速、数据万象 CI（图片裁剪/水印/审核）。
  • 权限模型：存储桶 ACL + 策略 + 临时密钥（STS），前端直传用临时密钥，别把永久密钥写进客户端。
  • 一致性：上传成功后立即可读（强一致），不必担心”刚传完读不到”。

5.5 选型决策口诀

六、数据库服务（10%）

6.1 产品全景

类别 产品 说明
关系型托管 TencentDB for MySQL / PostgreSQL / SQL Server / MariaDB 开箱即用、自动备份、主备高可用
分布式 TDSQL（MySQL 版 / PostgreSQL 版） 水平分片、分布式事务、金融级强一致
缓存 云数据库 Redis（标准版/集群版） 高并发读写、会话/热点缓存
文档 云数据库 MongoDB 灵活 schema、海量文档
时序 CTSDB 监控指标、IoT 数据
分析型 CDW 数据仓库 大规模 OLAP（见大数据章）
迁移同步 DTS 数据传输服务 迁移、实时同步、订阅

6.2 必考概念

  • 高可用形态：MySQL 双节点（一主一备，故障自动切换）；金融版/强同步（三节点，强一致但写入延迟略高）。
  • 只读实例：分担读流量，不是高可用（主库故障仍需切换，不靠只读实例顶上）。
  • 备份与 PITR：自动全量+增量备份，支持按时间点回档（误删数据恢复到删除前一刻），备份保留期可配。
  • 跨地域灾备：跨区备份 + DTS 同步 + 跨区只读实例，构成异地容灾。
  • TDSQL 的核心：SET 分片（水平拆分）+ 全局事务管理器，解决单机容量与分布式事务；适合订单、账务等金融场景。

6.3 托管 vs 自建

维度 云数据库托管 自建在 CVM 上
运维 自动备份、监控、故障切换 全部自己管
高可用 主备自动切换 自己做主从+Keepalived
弹性 在线升配、扩只读 停机或手工迁移
成本 单价高但省人力 便宜但隐性成本高
适用 生产环境、绝大多数业务 特殊版本、强定制、学习测试

选型关键词：题干出现”减少运维负担””自动备份””高可用” → 选托管；出现”需要 root 权限、特定插件、特殊版本” → 自建 CVM。

七、中间件服务（5%）

7.1 TDMQ 消息队列家族

产品 协议/生态 特点 场景
CKafka Kafka 兼容 超高吞吐、分区顺序、日志/埋点首选 日志采集、流式数据管道
TDMQ for RabbitMQ AMQP 路由灵活、队列模型丰富 业务解耦、任务分发
TDMQ for RocketMQ RocketMQ 事务消息、顺序消息、堆积能力强 电商订单、支付、金融
TDMQ for Pulsar Pulsar 多租户、存算分离、队列+流一体 大规模多业务共享

7.2 三个必考场景

  • 异步解耦：下单后发消息，积分/短信/物流各自消费，主链路不被拖慢。
  • 削峰填谷：秒杀流量先入队，后端按能力匀速消费。
  • 顺序与事务：订单状态变更必须保序（RocketMQ 顺序消息）；”扣库存+发消息”要原子（事务消息）。

选型判据：吞吐最大 → CKafka；路由灵活 → RabbitMQ；事务/顺序/金融 → RocketMQ；多租户大规模 → Pulsar。

八、安全服务（5%）

8.1 云原生安全体系（按层记）

层次 防护对象 腾讯云产品
网络边界 DDoS 攻击 DDoS 基础防护（免费）/ DDoS 高防（高防 IP、高防包）
应用层 SQL 注入、XSS、CC 攻击、爬虫 WAF Web 应用防火墙
网络流量 VPC 南北向/东西向访问控制 云防火墙
主机/工作负载 木马、漏洞、基线、入侵 CWPP 主机安全（云镜）、容器安全
数据 密钥、敏感数据 KMS 密钥管理、数据安全审计、数据安全治理中心
身份与权限 账号、授权、临时凭证 CAM 访问管理
审计与合规 操作记录、等保 云审计 CloudAudit、合规中心

8.2 逐个必记点

DDoS：

  • 基础防护：默认免费提供，攻击超过免费防护能力会触发封堵（黑洞），业务短时不可用。
  • 高防：BGP 高防 IP / 高防包，提供 T 级清洗能力、弹性防护、隐藏源站 IP。游戏、金融、政企是主要买家。

WAF：防护 OWASP Top 10（SQL 注入、XSS、命令注入等）、CC 攻击、恶意 BOT、自定义规则、防篡改；部署方式为 DNS 解析接入或 CLB 旁路接入。

CWPP 主机安全：木马查杀、漏洞检测与修复建议、基线合规（等保）、入侵检测、资产指纹。

云防火墙：VPC 边界的统一访问控制与流量审计，能管跨 VPC、跨子网的东西向流量（安全组管不到全局）。

KMS：托管主密钥、信封加密（数据密钥加密数据、主密钥加密数据密钥）、支持对称/非对称、可审计；与 COS/CBS/TencentDB 原生集成实现静态加密。

CAM 访问管理：

  • 根账号只做登录与 billing，日常用子账号；给子账号授权用策略（Policy）。
  • 角色（Role）用于跨账号访问、给云服务授权（如 COS 读 CVM）、联合身份（SSO），发的是临时密钥。
  • 原则：最小权限、按需授权、开启 MFA、密钥定期轮换。
  • 与 STS：临时访问凭证有有效期，前端直传 COS 必须用它，不能把永久密钥打到客户端。

九、大数据服务（10%）

9.1 上云的价值

弹性算力（跑完就释放）、存算分离（数据放 COS，计算按需拉起）、免运维（集群由平台管）、按量计费（离线任务成本可控）。

9.2 四个核心产品（分工必须分清）

产品 定位 关键特征
EMR 托管 Hadoop / Spark / Hive / Presto / Flink / HBase 集群 需要自己建集群、可控性强、适合复杂离线计算与数据湖
CDW 数据仓库 分析型数据库（ClickHouse 等引擎） 高性能 OLAP、固定集群、适合报表与即席查询
DLC 数据湖计算 Serverless SQL on COS 不建集群、直接查对象存储、按扫描量计费
WeData 一体化数据开发治理平台 数据集成、开发调度、ETL/ELT、数据质量、血缘、资产管理

9.3 其他常考点

  • 流计算 Oceanus：Flink 全托管，实时计算（实时大屏、实时风控）。
  • Elasticsearch Service：日志检索与分析（ELK 的托管版）。
  • TBDS：腾讯大数据处理套件，私有化部署版本（政务/金融本地化场景）。
  • 数据迁移：CDM 云数据迁移（本地/他云 → COS/EMR）、DTS（数据库）。

9.4 数据链路怎么串

选型判据：要”最省事、偶发查询对象存储” → DLC；要”高性能报表” → CDW；要”完整 Hadoop 生态、复杂作业” → EMR；要”全链路开发治理” → WeData。

十、AI 服务（12%）

10.1 AI 能力三层（先分层，再选产品）

层 内容 代表
基础设施层 GPU 算力、高速网络、存储 GPU 云服务器、高性能计算集群
平台层 训练/推理平台、AutoML TI 平台（TI-ONE）、TI-AutoML、TI 加速
应用层 开箱即用的 API/SaaS 人脸、OCR、语音、NLP、混元

判断口诀：有标注数据、要自己训模型 → 平台层（TI）；只要一个能力马上用 → 应用层 API。

10.2 平台层

  • TI 平台：可视化建模、Notebook、训练任务、模型仓库、在线推理服务；底层可对接 CVM/GPU/TKE。
  • TI-AutoML：自动特征工程 + 超参搜索 + 模型选择，低代码建模。
  • TI 加速：推理加速（量化、编译优化），降延迟降成本。
  • Angel：腾讯自研的分布式训练框架（大规模稀疏模型）。
  • 混元大模型 + 知识引擎 LKE：LKE 提供文档解析、切分、向量化、RAG 检索与问答编排，做企业知识库问答的标准路径。

10.3 应用层能力（题干关键词 → 产品）

需求关键词 产品/能力
图片里有什么、以图搜图 图像识别、图像标签、图像搜索
身份证/发票/名片识别 OCR 文字识别（通用/卡证/票据）
人脸比对、活体检测、实名核身 人脸识别、人脸核身
情感分析、分词、关键词、文本分类 自然语言处理 NLP
中英互译 机器翻译 TMT
语音转文字（实时/录音文件） 语音识别 ASR
文字转语音、配音 语音合成 TTS
声纹、语音唤醒 声纹识别、语音唤醒
文档问答、企业知识库 大模型知识引擎 LKE
生成文案/图片/对话 混元大模型 API

AI 服务的考试特点：几乎不考算法细节，只考”这个需求对应哪个产品能力”，以及”用 API 还是用平台自训”。

十一、企业应用服务（10%）

11.1 CDN 三兄弟（最易混）

产品 全称 加速对象 场景
CDN 内容分发网络 静态资源（图片、视频、JS/CSS、安装包） 网站加速、下载分发
ECDN 全站加速 动态请求 + 静态资源统一加速 动态接口多、跨运营商访问慢的站点
SCDN 安全加速 CDN + 安全防护（WAF/DDoS/防爬） 既要加速又要防攻击

CDN 必记：边缘节点缓存 + 回源、缓存刷新/预预热、防盗链（Referer/时间戳鉴权）、HTTPS 证书托管、按流量或带宽计费。

11.2 域名与解析

  • DNSPod：域名注册、DNS 解析、智能解析（按运营商/地域返回不同 IP）、负载均衡解析、宕机切换。
  • 私有域解析 Private DNS：内网域名解析，VPC 内自定义域名。
  • 域名必须实名认证并完成备案（境内服务器）才能对外提供 HTTP 服务。

11.3 SSL 证书

类型 校验内容 适用
DV 域名型 只验证域名所有权 个人站、测试环境
OV 组织型 验证企业真实身份 企业官网、电商
EV 增强型 最严格审核，浏览器显示企业名 金融、支付、品牌站

证书可一键部署到 CLB、CDN、COS 自定义域名，支持自动续期与托管。

11.4 其他企业服务

  • 建站：轻量应用服务器 + 建站模板/云市场镜像，快速上线小型站点。
  • 企业邮箱：域名邮箱、与微信/企业微信联动。
  • 云市场：第三方 SaaS/镜像/服务市场，按需订阅。
  • CODING DevOps：代码托管、CI/CD、制品库（SaaS + 私有化）。

十二、音视频与通信服务（5%）

产品 定位 关键能力
TRTC 实时音视频 低延迟互动 多人通话、互动直播、屏幕共享、终端 SDK（iOS/Android/Web/小程序），延迟在百毫秒级
TCCC 云联络中心 云呼叫中心 号码接入、IVR、坐席管理、通话录音、质检
VOD 视频点播 上传-转码-播放全链路 上传 SDK、转码模板、截图、水印、加密、防盗链、播放器
CSS 云直播 直播推拉流 推流、实时转码、录制、时移、鉴黄、直播水印
LEB 快直播 超低延迟直播 基于 WebRTC 的直播分发，延迟秒级降到百毫秒
音视频终端 SDK 端侧能力 美颜、变声、AI 特效

场景配对题：在线教育互动课堂 → TRTC；客服呼叫 → TCCC；课程回看 → VOD；大型公开课直播 → CSS/LEB。

十五、备考建议

三周节奏：

周 重点 目标
第 1 周 云服务器 + 网络 + 存储（占 40%） 能画出三层 Web 架构并说出每层产品
第 2 周 数据库 + 中间件 + 大数据 + AI（占 37%） 每个产品一句话定位、能选型
第 3 周 安全 + 企业应用 + 音视频（占 20%）+ 刷题 易混对照表能默写，模拟题稳定 80 分以上

方法：

  • 官方考点文档里的”考核重点”逐条对照本文，能说出”这个知识点对应哪个产品”就算过。
  • 免费模拟考试在开考前 5–7 天发给当期考生，一定要做，用来校准题型手感。
  • 多选题只选确定的：错选漏选都 0 分，宁少不多。

答题技巧：

  • 带 always / 只能 / 全部 的选项基本错。
  • “最省钱”和”最省运维”经常冲突，看清题干问的是哪个。
  • 看到”长期稳定”→ 包年包月；”临时/波动”→ 按量；”可中断”→ 竞价。
  • 不确定时选托管服务、选多可用区，这两个方向命中率最高。
