C#、.NET、ASP.NET三者的关系

  1. C#是一种面向对象的编程语言，是.NET Framework框架支持的一种主力开发语言。它主要用于开发跨平台的应用程序，如ASP.NET网站，Windows程序，控制台程序，甚至手机软件(Windows Phone)。它是.NET框架的一部分，并且可以在.NET平台上运行。

  2. .NET是微软开发的一个跨平台的应用框架和开发平台，由工具、编程语言、以及用于生成许多不同类型应用程序的库组成。它提供了统一的编程模型和库，可用于开发各种类型的应用程序。.NET支持多种编程语言，包括C#、Visual Basic、J#、Jsript和Managed C++等，并提供了丰富的类库和工具。.NET分成两个方面：

  • WinForm：C/S模式
  • WebForm：B/S模式
  1. ASP(Active Server Pages)是一种用于构建动态Web页面的技术，使用VBScript或JScript作为服务器端脚本语言。它是早期的Microsoft技术，现已逐渐过时。
  • ASP.NET是微软推出的下一代Web应用程序开发技术，它提供了更强大、更高效的功能和工具。ASP.NET可以使用多种语言如C#、Visual Basic等编程语言作为服务器端脚本语言(C#是最常用的)，并结合了面向对象的编程概念。
    • ASP.NET属于WebForm
  • ASP.NET Core是.NET平台上的新一代Web应用程序开发框架，它是ASP.NET的升级版本。与传统的ASP.NET相比，ASP.NET Core更加轻量级、高性能且跨平台。它采用了基于Razor的视图引擎和中间件管道模型，提供了更大的灵活性和可扩展性。

.NET组件-IIS8部署必装组件

  1. dotnet-hosting-5.0.17-win：针对服务器环境，特别是像IIS这样的Web服务器的运行时环境。它为服务器提供了.NET应用程序的运行时支持，使得.NET应用程序能够在服务器上正确运行。
  2. dotnet-sdk-5.0.408-win-x64：译为软件开发工具包，提供了开发.NET应用程序所需的所有工具和库。它包含了编译器、构建工具、调试器以及模板等，使得开发者可以在Visual Studio、VS Code或其他支持.NET的IDE中创建、构建、测试和发布.NET应用。SDK的作用主要是为了方便开发者在开发环境中编写、运行和调试.NET应用程序。

.NET和Java运行机制对比

  1. 各种语言(C#、F#、Visual Basic等源代码)——>经过CLS,CTS第一次编译——>生成.EXE/.DLL文件(实际生成中间语言IL(Intermediate Language)代码)——>JIT第二次编译——>二进制语言——>运行在CPU中
  2. Java语言——>编译——>字节码文件(.CLASS)——>jvm解释(jvm虚拟机)——>二进制语言——>运行在CPU中

.NET框架的组成分两部分/font>

  1. CLR：公共语言运行时(Common Language Runtime)，提供内存管理，代码安全性检测等功能。
  • CLS：公共语言规范，获取各种语言转换成统一的语法规范。
  • CTS：通用类型系统，将各种语言中的数据类型转换成统一的类型。
  • JIT：实时编译器(即时编译器)，用于将转换之后的语言编译为二进制语言，交给CPU执行。
  1. FLC：.NET框架类库(.NET Framework Class Library)，提供大量应用类库，类库中有很多线程的资源可使用(比如：类，方法，属性)以提高开发效率。
