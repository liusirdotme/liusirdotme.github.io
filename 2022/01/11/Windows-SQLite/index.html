Windows安装

一、下载与安装 SQLite（Windows 版）

  1. 下载 SQLite 工具包
  • 打开 SQLite 官方下载页：https://www.sqlite.org/download.html
  • 找到 Windows (x86) - DLL (x86) 区域，下载两个文件：
    • sqlite-dll-win32-x86-xxxxxxx.zip</font>（核心动态库）
    • sqlite-tools-win32-x86-xxxxxxx.zip</font>（命令行工具，包含 sqlite3.exe</font>）（xxxxxxx</font> 是版本号，选最新版即可）
  1. 解压并配置环境变量
  • 新建文件夹（推荐路径：C:\sqlite</font>），将两个压缩包的所有文件解压到该文件夹中；
  • 配置环境变量（让任意目录都能调用 sqlite3.exe</font>）：
    • 右键「此电脑」→「属性」→「高级系统设置」→「环境变量」；
    • 在「系统变量」中找到 Path</font>，点击「编辑」→「新建」；
    • 粘贴 SQLite 文件夹路径（如 C:\sqlite</font>），点击「确定」保存。
  1. 验证安装是否成功
  • 按下 Win + R</font>，输入 cmd</font> 打开命令提示符；
  • 输入 sqlite3</font> 并回车，若出现如下提示，说明安装成功：plaintext

三、可视化工具（可选，更友好）

  1. DB Browser for SQLite（免费开源）
  • 下载地址：https://sqlitebrowser.org/
  • 特点：图形化界面，支持建表、查询、导出数据，新手友好。
  1. 使用方法：
  • 安装后打开，点击「Open Database」选择 .db</font> 文件；
  • 可通过界面直接操作表和数据，无需手写 SQL 命令。

四、总结

  1. 安装核心：SQLite 无需安装，下载工具包解压后配置环境变量即可使用；
  2. 基础操作：通过 sqlite3 数据库名.db</font> 打开数据库，用标准 SQL 语句完成增删改查；
  3. 效率提升：新手推荐使用 DB Browser for SQLite 可视化工具，降低操作门槛。
